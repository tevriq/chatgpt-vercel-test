日常只需要“服务分流”。家庭 WAN 用于 HOME，手机 USB 用于 MOBILE。大类提供默认出口，缩进的小类默认跟随大类，也可以单独覆盖。

服务数据由 GitHub Action 从 v2fly/domain-list-community 生成并发布到 Cloudflare R2。0.8.1 中“检查更新”只检查 manifest；确认有新版本后，用户再点“更新服务数据”。

任一 WAN 不可用时保持 strict fail-closed：被指定到该 WAN 的流量直接失败，不偷偷改走另一条 WAN。局域网、回环、链路本地和 Tailscale 固定绕过。
