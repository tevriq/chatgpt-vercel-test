PRIMARY / INTL 是硬边界

两条出口不做自动互相回退。INTL 失败时，应该失败，而不是偷偷把本应走 INTL 的流量送到 PRIMARY。

90 秒事务

影响 live runtime 的变更会先试运行。用户确认才保留；超时、启动失败或最终配置校验失败都恢复上一版。

外置盘是 Authority

正常运行数据尽量落在外置存储。JFFS 保留必要启动组件、ADB runtime 与经过验证的应急只读 LKG。

ADB 是工具箱，不是流量判官

ADB 用来恢复 USB 网络、安装 APK、导出/诊断手机；WAN 是否可用应直接根据路由器网络接口状态判断。

Provider 先 Candidate 后 LKG

“检查更新”只产生候选，不立即改变 live runtime。应用候选才推进产品层 LKG，并进入同一套安全事务。

最终实现保持 Merlin 可落地

这个原型故意只用了普通 HTML / CSS / JavaScript。视觉可以现代一点，但不依赖 React 等重型框架，便于回落到 ASUS / Softcenter 页面。
