保留：0.9.0 fail-closed 修复

INTL 已正确 blackhole 时视为“安全阻断”，不是故障。自动恢复不得把它误修成 PRIMARY，也不得做 full reconcile 破坏安全状态。

保留：等待 Merlin 网络事实完整

USB WAN 刚连接时，接口/IP/网关尚未完整发布就不抢跑修路由；事实齐全后再判断是否需要恢复。

保留：WebUI last-good

一次状态请求失败不清空页面。已有数据继续显示并标记 stale；慢请求不能覆盖更新的数据。

保留：stale lock / request-scoped mutation

异常退出留下的锁必须可恢复；多页面同时操作不能靠全局 DBus 临时值互相覆盖。新实现继续采用服务端串行与请求级参数。

不继承：旧 Go runtime owner

Go controller / legacy owner 切换、旧 shell WAN reconciler 等只服务旧架构。#31 已决定运行层迁到 ShellCrash + Mihomo，因此不把这些实现重新搬回来。

不继承：旧 community/ipset 实现细节

AC88U 的 cksum fallback 属于旧 community runtime 的兼容修复。新架构只保留“设备兼容必须有 fallback/test”的原则，不保留旧数据面代码。
