使用说明

首页只放最重要的开关、模式和真实公网出口；服务分流负责服务/域名/IP走哪条出口；高级只保留规则测试、按设备固定出口和 YAML。

服务规则从哪里更新

当前 #31 从 GitHub 的 blackmatrix7/ios_rule_script 获取当前需要的规则，并强制通过 PRIMARY 下载。检查只形成 candidate；明确“应用更新”后才更新产品层 LKG，运行中进入 90 秒事务。

实际公网出口怎么确认

分别把请求绑定 PRIMARY / INTL，再访问公网查询接口。最终实现可组合 Cloudflare trace（公网 IP / PoP）与 IP metadata 服务（国家/城市/ASN/ISP）。WAN 变化时检测一次，也允许手动检测；不跟页面轮询持续访问公网。
